# 🚀 Terraform AWS Infrastructure

## 📌 Project Overview

This project provisions AWS infrastructure using Terraform.

## 🏗️ Architecture

VPC → Subnet → Internet Gateway → EC2 Instance

## 🧱 Resources

* AWS VPC
* Subnet
* Internet Gateway
* EC2 Instance

## ⚙️ Prerequisites

* AWS CLI configured
* Terraform installed

## ▶️ Execution Steps

terraform init
terraform plan
terraform apply

## 🧹 Cleanup

terraform destroy

## 📸 Output

* EC2 instance created
* Public IP generated

## 💡 Key Concepts Used

* Providers & Resources
* Variables & Outputs
* Implicit Dependencies
* Infrastructure as Code (IaC)
